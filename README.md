# guitar to keyboard

guitar2key is a simple tool that turns your electric guitar signals into keyboard button presses. Plug in your guitar, hit a note, and it triggers keys on your PC. It features a clean interface, custom key mapping, and saves all settings in a single file right next to the executable.
